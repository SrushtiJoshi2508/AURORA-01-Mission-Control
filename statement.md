AURORA-01 Mission Control

Problem Statement

AURORA-01 Mission Control is a Python-based command-line simulation designed to demonstrate how a mission control system can monitor spacecraft telemetry, perform diagnostics, simulate emergency situations, and make mission decisions.

The project provides a simple simulated environment where spacecraft parameters such as fuel, oxygen, temperature, battery, and altitude can be monitored and evaluated.

Scope

The project covers:
- Spacecraft telemetry monitoring
- System diagnostics
- Emergency simulation
- Mission decision-making
- Event logging
- Saving mission data
- Mission summary generation

This is an educational simulation and does not represent a real spacecraft control system.

Target Users

- Students learning Python programming
- Beginners interested in aerospace-related programming
- Students developing Python-based simulation projects

High-Level Features

1. Start and monitor a mission
2. View and update spacecraft telemetry
3. Perform system diagnostics
4. Simulate emergency conditions
5. Generate GO, CAUTION, or ABORT decisions
6. Maintain a mission event log
7. Save mission data to a file
8. Display a mission summary
