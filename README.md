# AURORA-01 — Mission Control Simulator

**Monitor. Diagnose. Decide. Survive.**

## 🚀 Project Overview

AURORA-01 is a command-line based Mission Control Simulator developed using Python.

The simulator represents a simplified aerospace mission-control system where the user can monitor spacecraft telemetry, perform system diagnostics, simulate emergencies, and make mission decisions.

## 🎯 Objectives

- Monitor spacecraft telemetry
- Detect critical and warning conditions
- Simulate emergency situations
- Generate mission decisions
- Maintain an event log
- Save mission data into a text file

## ⚙️ Features

1. Start Mission
2. View Telemetry
3. Run System Diagnostics
4. Simulate Emergency
5. Generate Mission Decision
6. View Mission Event Log
7. Save Mission Data
8. View Mission Summary

## 🛰️ Telemetry Parameters

The simulator monitors:

- Fuel Level
- Oxygen Level
- Temperature
- Battery Level
- Altitude

## 🚨 Mission Decisions

Based on telemetry values, the simulator can generate:

- GO
- CAUTION
- ABORT

## ▶️ How to Run

### Requirement

Python 3.9

### Run the program

Open `main.py` using Python IDLE and press:

`F5`

or run the file using Python from the terminal.

## 📋 Example Workflow

1. Start the mission.
2. Enter spacecraft telemetry.
3. Run diagnostics.
4. Simulate an emergency if required.
5. Generate the mission decision.
6. View the event log.
7. Save the mission data.
8. View the mission summary.
